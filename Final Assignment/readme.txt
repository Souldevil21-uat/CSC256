SkillSwap Hub - Final Project (JavaScript Web App)

Overview:
----------
This is a skill-matching application that allows users to:
- Enter their name, role, skills offered and desired.
- Select availability.
- Store data in local storage using JavaScript.

How to Run:
-----------
1. Place all files in the same folder (preserve css/ and js/ folders).
2. Open index.html in a browser.
3. Fill in the profile form and click "Save Profile".
4. Data is saved in your browser's local storage.

Technologies Used:
------------------
- HTML5 / CSS3
- JavaScript (ES6 Modules)
- No backend required

File Structure:
---------------
index.html           – main HTML page
css/style.css        – layout and styles
js/utils.js          – helper functions
js/data.js           – persistent user state
js/schedule.js       – schedule rendering
js/app.js            – main logic and interaction
